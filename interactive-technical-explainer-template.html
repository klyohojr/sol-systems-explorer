What it replaces—and what it doesn't.

  • Replaces a small custom interaction build for simple explainers
  • Replaces static-only system overview pages when clickable inspection is enough
  • Exports as portable HTML instead of requiring a web framework
It does not replace CAD, simulation, engineering review, a custom 3D/WebGL project, or an authoritative digital twin. If you need those, this is the wrong product.
