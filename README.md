# SOL Systems Explorer

**Browser-based interactive technical-explainer software for makers, educators, freelancers, creators, founders, designers, consultants, studios, agencies, and technical teams.**

SOL is useful when a buyer wants an interactive technical explainer, hardware/product architecture diagram, standalone HTML technical visualization, no-build product demo, or reusable interactive client deliverable — without building a web app from scratch.

## Demonstrated capabilities
Starter/Studio include editable JSON system data, browser interaction, mobile navigation, guided component tours, source/provenance links, relationship lines, multiple layouts, presentation/isolate modes, standalone HTML export, and PNG capture. Lite is intentionally smaller.

## Not for
SOL is not CAD authoring, engineering/physics simulation, a certified digital twin, safety-critical validation, live telemetry, or PLM/MBSE integration. No customer count, guaranteed ROI, certification, or AI-ranking guarantee is claimed.
